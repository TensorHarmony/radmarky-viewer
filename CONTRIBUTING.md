# Contributing

RadMarky Viewer is maintained by TensorHarmony Technologies Inc. The public
tree is available for inspection and local builds. Pull requests are reserved
for existing project contributors or changes explicitly requested by a
maintainer.

## Welcome

- Bug reports
- Feature requests
- Reproducible descriptions of a problem or a proposed fix

File these as GitHub issues. Do not include patient-identifiable medical data,
clinical binaries, or sample archives.

## Pull requests

Please open an issue before proposing a code change. Unsolicited pull requests
will be closed without review. Existing contributors should link the relevant
issue and describe the verification performed in the pull request.

This contributor-only policy is a supply-chain decision. Review alone is not
treated as a reliable way to keep untrusted code out of a desktop imaging
application.
